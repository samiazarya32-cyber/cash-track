# Cash Track 📊

Offline-First Multi-Language Accounting Progressive Web Application (PWA).

## Features
- 100% Offline operation via Dexie.js (IndexedDB).
- Multi-currency support (UGX, USD, KES, ERN, ETB).
- Plain language accounting (Income, Expenses, Debts).
- Automatic daily summary reports for WhatsApp sharing.
- Stock & Inventory quantity tracker.
